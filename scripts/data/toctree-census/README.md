# toctree block census — receipts

Generated by [`scripts/survey-toctree.ts`](../../survey-toctree.ts). Read that
file's docblock first: it carries the exact rules every number here depends on
(what counts as a blank line, a comment span, a trailing run, tail-to-EOF) and
the clone commands that rebuild each corpus.

These files are **receipts, not summaries**. The mid-file and `:glob:` lists are
complete — every path, not a sample — because those carriers are the subjects of
the phase-2 lock disposition in docs/19 and a sampled list cannot support a
disposition.

Regenerate all four (paths are this machine's; the docblock has the clones):

```sh
pnpm exec vite-node scripts/survey-toctree.ts ~/godot-docs \
  --label godot   --out scripts/data/toctree-census
pnpm exec vite-node scripts/survey-toctree.ts <corpora>/cpython --sub Doc \
  --label cpython --out scripts/data/toctree-census
pnpm exec vite-node scripts/survey-toctree.ts <corpora>/linux --sub Documentation \
  --label linux   --out scripts/data/toctree-census
pnpm exec vite-node scripts/survey-toctree.ts <corpora>/ansible --sub docs/docsite/rst \
  --label ansible --out scripts/data/toctree-census
```

finding.

table is `grep -h '^SUMMARY' *.txt` rather than four numbers retyped by hand.
